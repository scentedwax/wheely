# 🔮 Wheely

> Задай вопрос — получи ответ.

Wheely — приложение-оракул. Загадай вопрос, крути колесо
и получи забавный вердикт: «Однозначно да», «Даже не думай»,
«Наберись смелости» и другие.

<img width="800" height="1189" alt="photo_4" src="https://github.com/user-attachments/assets/38aadec7-1eca-4ae1-adb2-89e438fb17ce" />

## ✨ Возможности
- 🔮 16 стандартных ответов оракула
- 🌑 Тёмная мистическая тема
- 📳 Вибрация при остановке (Android)
- 📱 Android, Linux, Windows, macOS (Kivy)

## 🛠️ Стек
- Python 3.11
- Kivy 2.3
- Buildozer (Android)
